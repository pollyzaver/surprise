# Лендинг «Сюрприз» — первая рабочая версия

Ансамбль танца «Сюрприз», Оренбург. Кейс 04, учебный проект по дисциплине
«Компьютерный дизайн» (практики 3–5).

## Как запустить

```bash
cd ~/Desktop/portfolio-brand/sites/04-syurpriz
npm install
npm run dev
```

- `npm install` — ставит зависимости (нужно один раз).
- `npm run dev` — поднимает локальный сервер. В терминале появится ссылка
  **http://localhost:5173** — открой её в браузере. Страница сама
  перезагружается, когда правишь файлы.
- `Ctrl + C` в терминале — остановить сервер.

Перед сдачей и перед деплоем:

```bash
npm run lint    # ESLint. Должно быть пусто — на ошибках падает сборка Vercel
npm run build   # production-сборка в папку dist
npm run preview # посмотреть собранную версию, ссылка http://localhost:4173
```

## Где что править

| Что меняешь | Файл |
|---|---|
| Любой текст, подписи, адреса, подбор кадров | `src/data/content.js` |
| Цвета, шрифты, отступы, сетка, зерно | `src/styles/tokens.css` |
| Общие стили: кнопки, поля, типографика | `src/styles/base.css` |
| Оформление конкретной секции | `src/styles/sections.css` (секции идут в том же порядке, что на странице) |
| Структура и порядок секций | `src/App.jsx` |
| Разметка одной секции | `src/sections/<Имя>.jsx` |

Вордмарк — настоящие контуры из `cases/04-syurpriz/assets/syurpriz-wordmark-mono.svg`,
перенесённые в `src/components/Wordmark.jsx`. Цвет задаётся через CSS `color`,
шрифтом он нигде не набран.

## Что осталось заполнить

На странице заглушки подсвечены голубой плашкой — их видно глазом:

- `[название постановки]` — три кластера в тёмном блоке «Как это выглядит со сцены».

Форма записи пока не отправляется: проверяет поля и показывает подтверждение
на клиенте. Точка подключения — `handleSubmit` в `src/sections/Signup.jsx`.

## Шрифты

- **Soledago** (`public/fonts/Soledago.woff2`) — заголовки и крупные цифры.
  Автор Alexandra Gophmann выложил шрифт свободно, но формальной OFL нет.
  Для учебной практики это нормально. Перед публичным деплоем сайта ансамбля —
  либо подтверждение автора, либо заголовки в кривых.
- **Roboto Slab** (OFL) — весь остальной текст, кикеры, кнопки.

## Изображения

Все кадры — реальный архив коллектива, пережаты в webp (`public/media`,
около 1,2 МБ на всю страницу). Вырезки с альфа-каналом — Photoroom, обрезаны
по содержимому. Кадры с чужими логотипами в углу обрезаны при экспорте или
кропом через `position` в `content.js`.
