# Публикация сайта на Vercel и заявки в Телеграм

Сайт публикуется на Vercel из репозитория GitHub. Vercel сам собирает сайт
и запускает функцию `api/signup.js`: она принимает заявки из формы и
пересылает их тебе в Телеграм. Отдельного облака настраивать не нужно.

Бесплатный тариф Vercel (Hobby) рассчитан на некоммерческие проекты,
портфолио под это подходит. Из России Vercel открывается не у всех
провайдеров: перед защитой проверь ссылку с телефона через мобильный интернет.

## 1. Отправить код на GitHub

```bash
cd ~/Desktop/portfolio-brand/sites/04-syurpriz
git add -A
git commit -m "Политика, согласие, отправка заявок в Телеграм, подготовка к публикации"
git push
```

## 2. Бот в Телеграме

1. Если ключ бота кому-то пересылался — в @BotFather отправь `/revoke`,
   выбери бота и возьми новый ключ.
2. Нажми **Start** у своего бота (без этого он не сможет тебе писать).
3. Узнай свой **Id**: напиши что угодно боту @userinfobot.

## 3. Проект на Vercel

1. Зайди на vercel.com → **Sign Up** → **Continue with GitHub**.
2. **Add New… → Project** → найди репозиторий `surprise` → **Import**.
3. Framework Preset определится сам: **Vite**. Остальное не трогай
   (Build Command `npm run build`, Output Directory `dist`).
4. Раскрой **Environment Variables** и добавь две переменные:
   | Key | Value |
   |---|---|
   | `TG_BOT_TOKEN` | ключ бота |
   | `TG_CHAT_ID` | твой Id |
5. **Deploy**. Через минуту появится ссылка вида `surprise-xxxx.vercel.app`.

## 4. Проверить

Открой ссылку, заполни форму записи — в Телеграм придёт
«Новая заявка на пробное занятие».

Дальше всё обновляется само: после каждого `git push` Vercel заново
публикует сайт.

## Если заявка не пришла

- Vercel → проект → **Logs**: там будет строка с ошибкой (`telegram: ...`).
- `no_channels` — не заданы переменные. Добавь их в **Settings →
  Environment Variables** и нажми **Redeploy** (переменные применяются
  только к новой публикации).
- `chat not found` — не нажата кнопка Start у бота или неверный Id.

## ВКонтакте (потом)

Когда будет доступ к сообществу: создай в нём ключ доступа с правом на
сообщения, напиши сообществу одно сообщение от своей страницы и добавь
на Vercel переменные `VK_TOKEN` и `VK_USER_ID` (твой числовой id).
Код менять не нужно.

## Локально

При `npm run dev` функции нет, поэтому форма работает как макет:
сразу показывает «Заявка записана» и ничего не отправляет.
